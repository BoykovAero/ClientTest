## Как устроено

```
data/<период>.json     исходные данные — единственное место, которое правят руками
ai_digest/models.py    модель данных и проверки
ai_digest/render.py    рендеринг в Markdown
ai_digest/__main__.py  CLI
docs/digest-<период>.md  сгенерированный результат (не править вручную)
tests/                 тесты, в том числе валидация данных из data/
```

## Запуск

Зависимостей для генерации нет — только стандартная библиотека Python 3.10+.

```bash
python -m ai_digest                  # собрать Markdown по всем периодам
python -m ai_digest --period 2026-08 # только один период
python -m ai_digest --check          # проверить данные, ничего не записывая
```

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest tests -q
```

## Добавить новый выпуск

1. Создайте `data/<год>-<месяц>.json` по образцу существующего.
2. Проверьте: `python -m ai_digest --check`.
3. Сгенерируйте: `python -m ai_digest`.
4. Закоммитьте и JSON, и полученный Markdown.

Требования к данным, которые проверяет код: у каждой новости уникальный `id`,
категория из списка в `ai_digest/models.py`, непустые `headline`, `body`,
`why_it_matters` и хотя бы один источник на `https://`.
